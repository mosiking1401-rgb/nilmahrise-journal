⚙️ تنظیمات ارسال SMS و Email

📱 حالت فعلی: توسعه (Development)

در این حالت، کد OTP روی صفحه نمایش داده می‌شود و پیامک واقعی ارسال نمی‌شود. برای فعال‌سازی SMS واقعی، از پنل ایرانی زیر استفاده کنید:

📱 پیکربندی SMS (کاوه‌نگار)

1️⃣ در کاوه‌نگار ثبت‌نام کنید (رایگان + شارژ اولیه)

2️⃣ API Key خود را دریافت کنید

3️⃣ در پنل، الگو (template) بسازید مثلاً: "کد تایید NilmahRise: %token"

4️⃣ ⚠️ توجه: به دلیل محدودیت CORS، این تنظیمات فقط با یک Backend یا Cloudflare Worker کار می‌کند

✉️ پیکربندی Email (EmailJS - رایگان)

1️⃣ در EmailJS.com ثبت‌نام کنید (200 ایمیل رایگان/ماه)

2️⃣ Service ID، Template ID و Public Key دریافت کنید

3️⃣ در Template متغیر {{otp_code}} و {{to_email}} بگذارید
